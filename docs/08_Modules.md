# Module Documentation

CloudShield Enterprise consists of the following modules.

---

Authentication

Provides secure login and user management.

---

Dashboard

Displays overall platform statistics.

---

Scanner

Performs vulnerability assessments.

---

Assets

Manages organizational assets.

---

Findings

Displays identified vulnerabilities.

---

Analytics

Generates security statistics and charts.

---

Reports

Exports reports in PDF, CSV, and JSON.

---

Notifications

Displays security alerts.

---

Settings

Allows user configuration.

---

Docker

Manages Docker resources.

---

Cloud

Provides AWS monitoring.

---

Executive Dashboard

Displays management-level security summaries.

---

REST API

Supports third-party integrations.
