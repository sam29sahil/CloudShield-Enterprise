# Security Policy

## Supported Versions

| Version | Supported |
|----------|-----------|
| 1.x | ✅ |

---

## Reporting a Vulnerability

If you discover a security vulnerability in CloudShield Enterprise, please report it responsibly.

Include:

- Description
- Steps to reproduce
- Impact
- Suggested fix

Please do not publicly disclose vulnerabilities until they have been reviewed.

---

## Security Features

CloudShield currently provides:

- Password Hashing
- Secure Authentication
- Session Management
- Input Validation
- CSRF Protection
- Docker Integration
- AWS Integration
